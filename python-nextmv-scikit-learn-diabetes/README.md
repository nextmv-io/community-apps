# Nextmv & scikit-learn Diabetes

This community app contains a Jupyter Notebook that demonstrates how to use the
`nextmv-scikit-learn` package, which was created to facilitate the integration
of Nextmv and scikit-learn.

The classical diabetes dataset is used with different regressors to:

1. train a scikit-learn model,
2. fit it,
3. export the fitted model (solution),
4. import the model,
5. make predictions.

The notebook showcases how to achieve this, step by step.
